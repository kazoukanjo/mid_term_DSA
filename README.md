# Hệ Thống Thi Thử Giữa Kỳ — Cấu Trúc Dữ Liệu & Thuật Toán (IT3011)

Ứng dụng web tĩnh (HTML / CSS / JavaScript) gồm **10 đề thi thử** bám sát cấu trúc đề thi giữa kỳ học phần **IT3011 - Cấu trúc dữ liệu và thuật toán** (Đại học Bách khoa Hà Nội) và toàn bộ nội dung bài giảng.

## Tính năng chính
- **10 Đề thi độc lập (330 câu hỏi có lời giải ngắn gọn)**: Mỗi đề gồm **30 câu Trắc nghiệm** (7.5 điểm) và **3 câu Trả lời ngắn** (2.5 điểm).
- **Đồng hồ đếm ngược 50 phút** chuẩn thời lượng thi giữa kỳ, tự động nộp bài khi hết giờ.
- **Phân loại độ khó & Chuyên đề**: Dễ (12 câu), Trung bình (13 câu), Khó (8 câu) trải đều các chủ đề: Độ phức tạp chương trình/thuật toán, Đệ quy & Chia để trị, Danh sách liên kết, Ngăn xếp & Hàng đợi, Cây & Cây nhị phân, Quay lui & Nhánh cận, Quy hoạch động & Tham lam.
- **Tự động chấm điểm & Thống kê chi tiết**: Quy đổi thang điểm 10, phân tích tỷ lệ đúng theo từng mức độ khó và từng chuyên đề, lưu điểm cao nhất vào trình duyệt (`localStorage`).
- **Giao diện Sáng / Tối (Dark Mode)** thân thiện, hỗ trợ trên cả máy tính và điện thoại.

## Hướng dẫn đưa lên GitHub Pages để chia sẻ
1. Tạo một Repository mới trên GitHub (ví dụ: `it3011-dsa-mock-exam`).
2. Tải toàn bộ 5 tệp (`index.html`, `style.css`, `app.js`, `questions.js`, `README.md`) lên thư mục gốc của Repository.
3. Vào **Settings** → **Pages** → tại mục **Build and deployment**, chọn Branch `main` (thư mục `/ (root)`) và nhấn **Save**.
4. Sau khoảng 1 phút, GitHub sẽ cung cấp đường link công khai (`https://<username>.github.io/it3011-dsa-mock-exam/`) để bạn chia sẻ cho bạn bè cùng ôn tập!
